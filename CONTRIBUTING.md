# Участие в разработке

Спасибо за интерес к **MOE Optimizator**.

## Перед началом

1. Прочитайте [docs/process.md](docs/process.md) — согласование фич и формат решения проблем.
2. Настройте окружение: [docs/getting-started.md](docs/getting-started.md).

## Локальная проверка

```bash
make install-dev
make check
```

## Pull request

- Один PR — одна согласованная тема
- Обновите документацию в `docs/`, если меняется поведение, сборка или структура
- Сборка `.exe` проверяется в CI на Windows (см. [docs/ci.md](docs/ci.md))

## Вопросы и фичи

Новые возможности сначала обсуждаем (issue, чат, roadmap) — затем реализуем после явного согласия.

Полная документация: [docs/README.md](docs/README.md).
